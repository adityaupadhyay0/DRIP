# DRIP — Intelligent Fashion Decision Platform

DRIP is an open-source, AI-powered intelligent fashion decision platform. It is a **personal fashion operating system** — a system that understands who you are, what you own, what suits you, and what you should buy next — then helps you act on that with confidence.

## 🚀 Vision

Current fashion ecommerce optimizes for transactions. DRIP optimizes for **confidence**.

## ✨ Key Features

- **Intent-Driven Search**: Natural language search across aggregated catalogs.
- **Visual Discovery**: Upload inspiration and find shoppable alternatives.
- **Smart Wardrobe**: Digitize your closet and get AI-powered compatibility advice.
- **Persona Engine**: Adaptive UI and recommendations based on your unique aesthetic.

## 🛠 Tech Stack

- **Frontend**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase + NextAuth.js
- **AI**: Claude / GPT-4V / Gemini (swappable)

## 🏁 Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`.
3. Copy `.env.example` to `.env.local` and fill in your keys.
4. Run the development server: `npm run dev`.
